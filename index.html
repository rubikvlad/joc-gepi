Name That Clip

Welcome to Name That Clip

You hear a few seconds of a song and guess the title. Guess early for more points, or skip to hear a longer clip. Each song also gets one free jump to a different part of the track.

Two ways to play

Artist. Pick any artist and play their most popular songs, or only the albums you choose. It works right away with nothing to set up.

YouTube playlist. Build your own mix from YouTube links or import a YouTube playlist. This also works without any setup, with two limits: imports stop at 200 songs, and YouTube search is off.

About the YouTube API key

To search YouTube from inside the app or import bigger playlists, add your own YouTube API key. It's free and takes about 5 minutes. Everyone needs their own, because each key has its own daily limit.

How to get a key
  1. Go to console.cloud.google.com, sign in with a Google account, and create a project.
  2. Open APIs & Services, then Library. Search for YouTube Data API v3 and click Enable.
  3. Go to APIs & Services, then Credentials, and choose Create credentials, then API key.
  4. Recommended: edit the key, set Application restrictions to Websites, and add . Under API restrictions, pick only YouTube Data API v3.
  5. Paste the key on the YouTube playlist tab, under "YouTube API key".

Your key, playlists, and settings are saved only in your own browser. This site has no server, so none of it is sent to whoever runs it. Your key is used only to talk to YouTube directly.
Artist mode works as is, but YouTube playlists won't play on pages opened straight from disk. In the folder with this file, run python -m http.server 8000 and open http://localhost:8000/song-guesser.html.
